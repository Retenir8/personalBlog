## 🎯 功能特性

### 核心功能
- [x] 部分更新：只更新请求中包含的字段
- [x] 字段保护：未包含的字段保持原值不变
- [x] Gender 字段：支持中文值（"男"/"女"/"未知"）
- [x] 空值处理：null 和空字符串不更新字段（Gender 特殊处理）
- [x] 权限控制：保留原有的权限验证逻辑
- [x] 用户验证：检查用户是否存在

### 支持的字段
- [x] name (用户名)
- [x] gender (性别)
- [x] avatarUrl (头像 URL)
- [x] hobbies (爱好)
- [x] healthCondition (健康状况)

### Gender 字段支持
- [x] 中文值：`"男"`, `"女"`, `"未知"`
- [x] 枚举名：`"MALE"`, `"FEMALE"`, `"UNKNOWN"` (大小写不敏感)
- [x] 空字符串：不更新字段
- [x] null 值：不更新字段
- [x] 无效值：不更新字段（不抛出异常）
