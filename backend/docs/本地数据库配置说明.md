# 唐社选课平台本地数据库配置

## 数据库规划

- PostgreSQL 地址：`127.0.0.1:5432`
- 专用数据库：`tang_course_platform`
- 专用登录用户：`tang_course_app`
- 权限范围：仅登录并拥有项目数据库；无超级用户、建库、建角色和复制权限
- 表结构来源：`resources/schema.sql`

应用用户的随机密码只写入项目根目录的 `.env.local`。该文件已加入 `.gitignore`，不得提交到版本库。

## 首次创建

在后端项目目录运行：

```powershell
.\scripts\setup-database.ps1
```

脚本会安全提示输入 PostgreSQL 管理员密码，不会把管理员密码写入文件。它会依次创建或更新专用用户、创建数据库、初始化表结构，并生成 `.env.local`。

如果 PostgreSQL 安装位置不同：

```powershell
.\scripts\setup-database.ps1 `
  -PsqlPath "C:\Program Files\PostgreSQL\17\bin\psql.exe" `
  -CreatedbPath "C:\Program Files\PostgreSQL\17\bin\createdb.exe"
```

## 启动后端

```powershell
.\scripts\run-local.ps1
```

脚本会把 `.env.local` 加载为当前进程环境变量，检测 Java 21，再在 `3001` 端口启动 Spring Boot。前端默认 API 地址为 `http://localhost:3001/api`。如果未自动找到 Java 21，可使用 `-JavaHome "你的 JDK 21 目录"` 指定。

## 生成模拟数据

后端启动后运行：

```powershell
.\scripts\seed-mock-data.ps1
```

脚本可重复执行，会创建 6 名模拟学员、1 名教师、1 名护理员、10 门课程、12 条报名关系、4 条健康记录和 4 条活动预告。模拟账号统一密码为 `Demo@123456`；教师账号为 `demo_teacher`，护理员账号为 `demo_caregiver`。

## 接口自动化测试

后端服务启动后，可运行覆盖认证、用户资料、课程管理、报名和权限校验的冒烟测试：

```powershell
$env:TEST_ADMIN_PASSWORD = "你的管理员密码"
.\scripts\test-api.ps1
```

测试过程中产生的临时课程和临时用户会在结束时自动清理。

## 验证

```powershell
$env:PGPASSWORD = (Get-Content .env.local | Where-Object { $_ -like "DB_PASSWORD=*" }).Split("=", 2)[1]
& "D:\Program Files\postgresql\bin\psql.exe" -h 127.0.0.1 -U tang_course_app -d tang_course_platform -c "\dt"
Remove-Item Env:PGPASSWORD
```

应能看到 `users`、`courses`、`course_enrollments` 和 `file_uploads` 等项目表。生产环境必须另外设置高强度 JWT 密钥和真实的 R2 配置。
