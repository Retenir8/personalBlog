## 📋 功能说明

### 部分更新行为
| 请求字段 | 行为 |
|---------|------|
| 包含在请求中且非 null | ✅ 更新该字段 |
| 包含在请求中但为 null | ❌ 不更新该字段 |
| 不包含在请求中 | ❌ 不更新该字段 |

### Gender 字段特殊处理
| 输入值 | 结果 |
|--------|------|
| `"MALE"`, `"male"`, `"Male"` | ✅ 更新为 MALE |
| `"FEMALE"`, `"female"` | ✅ 更新为 FEMALE |
| `"UNKNOWN"`, `"unknown"` | ✅ 更新为 UNKNOWN |
| `"男"` | ✅ 更新为 MALE |
| `"女"` | ✅ 更新为 FEMALE |
| `"未知"` | ✅ 更新为 UNKNOWN |
| `""` (空字符串) | ❌ 不更新 |
| `null` | ❌ 不更新 |
| 其他无效值 | ❌ 不更新 |

## 🔧 API 使用示例

### 基本用法
```bash
# 只更新名字
curl -X PUT http://localhost:8080/api/user/1 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "新名字"}'

# 只更新性别
curl -X PUT http://localhost:8080/api/user/1 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"gender": "男"}'

# 更新多个字段
curl -X PUT http://localhost:8080/api/user/1 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "张三",
    "hobbies": "书法, 太极",
    "healthCondition": "健康"
  }'
```

## ⚠️ 注意事项

### 1. 权限控制
- 普通用户只能修改自己的信息
- 管理员可以修改所有用户信息
- 违反权限会返回 403 Forbidden

### 2. Gender 字段
- 空字符串 `""` 不会更新字段
- 无效值不会导致错误，只是不更新
- 推荐使用枚举名称（MALE/FEMALE/UNKNOWN）或中文值（男/女/未知）

### 3. 字段验证
- 确保 userId 存在，否则返回 404
- 所有字段都是可选的
- 至少需要包含一个字段

## 🐛 常见问题

### Q: 为什么我的字段没有被更新？
A: 检查以下几点：
1. 字段是否在请求体中？
2. 字段值是否为 null？
3. Gender 字段是否为空字符串或无效值？

### Q: 如何清空某个字段？
A: 对于字符串字段（除 Gender 外），传入空字符串 `""`：
```json
{
  "hobbies": ""
}
```

### Q: Gender 字段如何清空？
A: Gender 字段目前不支持清空（设置为 null）。如果需要此功能，需要额外的实现。
