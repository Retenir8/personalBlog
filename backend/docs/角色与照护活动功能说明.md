# 角色、照护记录与活动预告功能说明

## 用户类别与权限

| 用户类别 | 角色值 | 主要权限 |
| --- | --- | --- |
| 普通用户 | `user` | 查看近期活动、浏览和报名课程、查看自己的健康记录与个人资料 |
| 教师 | `teacher` | 浏览课程、进入课程工作台、创建/修改/删除课程、查看课程报名名单 |
| 护理员 | `caregiver` | 查看长者名单、添加和查看身心状态及检查记录、发布和撤下活动预告 |
| 管理员 | `admin` | 用户和角色管理、课程管理、照护记录与活动预告管理 |

公开注册仍创建普通用户。管理员可在“用户管理”页面把普通用户调整为教师或护理员。

## 新增接口

- `PUT /api/admin/user/{userId}/role`：管理员修改用户类别。
- `GET /api/care/users`：护理员或管理员查看普通用户列表。
- `GET /api/care-records/user/{userId}`：护理员/管理员查看任意长者记录；普通用户只能查看自己。
- `POST /api/care-records`：护理员或管理员添加健康检查记录。
- `DELETE /api/care-records/{recordId}`：护理员或管理员删除误录记录。
- `GET /api/activities`：查看即将开展的活动。
- `POST /api/activities`：护理员或管理员发布活动预告。
- `DELETE /api/activities/{activityId}`：护理员或管理员撤下活动。

教师和管理员都可以调用原有的课程创建、修改、删除以及报名名单接口。

## 数据库升级

现有数据库执行：

```powershell
$env:PGPASSWORD = "项目数据库用户密码"
psql -h 127.0.0.1 -U tang_course_app -d tang_course_platform `
  -f resources/migrations/003_add_staff_care_and_activities.sql
```

完整初始化使用 `resources/schema.sql`，会直接创建四类角色约束、`care_records` 和 `activities` 表。
