# 文件上传功能 - 快速开始指南

## 🚀 三步启动文件上传功能

### 第一步：配置 Cloudflare R2

#### 1.1 在 `application.yaml` 中添加配置

在 `src/main/resources/application.yaml` 文件末尾添加：

```yaml
# Cloudflare R2 存储配置
cloudflare:
  r2:
    access-key: "your-r2-access-key"          # 替换为你的 R2 Access Key
    secret-key: "your-r2-secret-key"          # 替换为你的 R2 Secret Key
    bucket-name: "your-bucket-name"           # 替换为你的存储桶名称
    endpoint: "https://your-account-id.r2.cloudflarestorage.com"  # 替换为你的端点
    region: "auto"
    public-url: "https://your-custom-domain.com"  # 替换为你的公开访问域名

# Spring 文件上传配置
spring:
  servlet:
    multipart:
      max-file-size: 5MB
      max-request-size: 10MB
      enabled: true
```

#### 1.2 获取 R2 凭证

1. 登录 Cloudflare 控制台：https://dash.cloudflare.com/
2. 进入 **R2** 页面
3. 创建存储桶（如果还没有）
4. 点击 **管理 R2 API 令牌** → **创建 API 令牌**
5. 复制 **Access Key ID** 和 **Secret Access Key**
6. 复制存储桶的 **S3 API 端点**

### 第三步：启动应用并测试

#### 3.1 启动应用

```bash
./mvnw spring-boot:run
```

#### 3.2 测试上传接口

使用 curl 测试：

```bash
# 1. 先登录获取 token
curl -X POST http://localhost:8080/api/login \
  -H "Content-Type: application/json" \
  -d '{"username":"your-username","password":"your-password"}'

# 2. 使用返回的 token 上传文件
curl -X POST http://localhost:8080/api/upload/image \
  -H "Authorization: Bearer <your-token>" \
  -F "file=@/path/to/your/image.jpg" \
  -F "fileType=avatar"
```

或使用 Postman：

1. **请求方式**：POST
2. **URL**：`http://localhost:8080/api/upload/image`
3. **Headers**：
    - `Authorization`: `Bearer <your-token>`
4. **Body**：选择 `form-data`
    - Key: `file`, Type: `File`, Value: 选择图片文件
    - Key: `fileType`, Type: `Text`, Value: `avatar`（可选）

#### 3.3 预期响应

```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "image_url": "/uploads/2024/10/24/a1b2c3d4-e5f6-7890-abcd-ef1234567890.jpg",
    "file_id": 1
  }
}
```

## 📝 前端集成示例

### HTML + JavaScript

```html
<!DOCTYPE html>
<html>
<head>
    <title>文件上传测试</title>
</head>
<body>
    <h1>上传头像</h1>
    <input type="file" id="fileInput" accept="image/*">
    <button onclick="uploadFile()">上传</button>
    <div id="result"></div>

    <script>
        const token = 'your-jwt-token'; // 替换为实际的 token

        async function uploadFile() {
            const fileInput = document.getElementById('fileInput');
            const file = fileInput.files[0];
            
            if (!file) {
                alert('请选择文件');
                return;
            }

            const formData = new FormData();
            formData.append('file', file);
            formData.append('fileType', 'avatar');

            try {
                const response = await fetch('/api/upload/image', {
                    method: 'POST',
                    headers: {
                        'Authorization': `Bearer ${token}`
                    },
                    body: formData
                });

                const result = await response.json();
                
                if (result.code === 200) {
                    document.getElementById('result').innerHTML = 
                        `<p>上传成功！</p>
                         <p>文件路径：${result.data.image_url}</p>
                         <img src="${result.data.image_url}" width="200">`;
                } else {
                    alert('上传失败：' + result.message);
                }
            } catch (error) {
                alert('上传出错：' + error.message);
            }
        }
    </script>
</body>
</html>
```

### React 示例

```jsx
import React, { useState } from 'react';
import axios from 'axios';

function FileUpload() {
  const [file, setFile] = useState(null);
  const [uploading, setUploading] = useState(false);
  const [imageUrl, setImageUrl] = useState('');

  const handleFileChange = (e) => {
    setFile(e.target.files[0]);
  };

  const handleUpload = async () => {
    if (!file) {
      alert('请选择文件');
      return;
    }

    const formData = new FormData();
    formData.append('file', file);
    formData.append('fileType', 'avatar');

    setUploading(true);

    try {
      const token = localStorage.getItem('token');
      const response = await axios.post('/api/upload/image', formData, {
        headers: {
          'Authorization': `Bearer ${token}`,
          'Content-Type': 'multipart/form-data'
        }
      });

      if (response.data.code === 200) {
        setImageUrl(response.data.data.image_url);
        alert('上传成功！');
      } else {
        alert('上传失败：' + response.data.message);
      }
    } catch (error) {
      alert('上传出错：' + error.message);
    } finally {
      setUploading(false);
    }
  };

  return (
    <div>
      <h2>上传头像</h2>
      <input type="file" accept="image/*" onChange={handleFileChange} />
      <button onClick={handleUpload} disabled={uploading}>
        {uploading ? '上传中...' : '上传'}
      </button>
      {imageUrl && (
        <div>
          <p>上传成功！</p>
          <img src={imageUrl} alt="上传的图片" width="200" />
        </div>
      )}
    </div>
  );
}

export default FileUpload;
```

## ⚠️ 常见问题

### Q1: 上传失败，提示 "文件上传到云存储失败"

**解决方法**：

1. 检查 `application.yaml` 中的 R2 配置是否正确
2. 确认 Access Key 和 Secret Key 是否有效
3. 验证存储桶名称和端点 URL
4. 检查服务器网络连接

### Q2: 提示 "文件大小不能超过 5MB"

**解决方法**：

- 压缩图片后再上传
- 或调整 `application.yaml` 中的 `max-file-size` 配置

### Q3: 提示 "不支持的文件类型"

**解决方法**：

- 仅支持 JPG、PNG、GIF、WEBP 格式
- 检查文件扩展名是否正确

### Q4: 上传成功但无法访问文件

**解决方法**：

1. 在 Cloudflare 控制台启用存储桶公开访问
2. 或配置自定义域名
3. 更新 `application.yaml` 中的 `public-url` 配置
