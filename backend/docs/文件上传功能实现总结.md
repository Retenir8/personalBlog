# 文件上传功能实现总结

## 📋 实现概述

已成功实现基于 **Cloudflare R2** 的完整文件上传解决方案，符合 API 文档规范，提供安全、可靠的图片上传服务。

## ✅ 已完成的功能

### 1. 核心功能

- ✅ **文件上传接口**：`POST /api/upload/image`
- ✅ **文件删除接口**：`DELETE /api/upload/{fileId}`（逻辑删除）
- ✅ **Cloudflare R2 集成**：使用 AWS S3 SDK 连接 R2
- ✅ **数据库记录管理**：完整的文件上传记录追踪

### 2. 文件验证

- ✅ **文件类型限制**：仅支持 `image/jpeg`, `image/png`, `image/gif`, `image/webp`
- ✅ **文件大小限制**：单文件最大 5MB
- ✅ **双重验证**：同时验证 MIME 类型和文件扩展名
- ✅ **空文件检查**：防止上传空文件

### 3. 文件存储策略

- ✅ **命名策略**：UUID + 原始扩展名（避免冲突和安全问题）
- ✅ **目录组织**：按日期分层存储 `/uploads/YYYY/MM/DD/`
- ✅ **路径返回**：返回相对路径（不包含基础 URL）
- ✅ **重复处理**：UUID 确保文件名唯一性

### 4. 安全性

- ✅ **JWT 认证**：所有接口需要登录认证
- ✅ **用户追踪**：记录上传者 ID
- ✅ **路径安全**：UUID 命名防止路径遍历攻击
- ✅ **类型白名单**：仅允许特定文件类型

### 5. 错误处理

- ✅ **文件验证异常**：文件类型、大小不符合要求
- ✅ **上传失败异常**：R2 上传失败处理
- ✅ **IO 异常**：文件读取失败处理
- ✅ **文件大小超限异常**：Spring 文件上传大小限制

## 🔧 技术实现细节

### 1. R2 存储配置 (`R2StorageConfig.java`)

**功能**：

- 配置 AWS S3 客户端连接 Cloudflare R2
- 使用 `@ConfigurationProperties` 读取配置
- 启用路径样式访问（R2 要求）

**关键代码**：

```java
@Bean
public S3Client s3Client(R2Properties r2Properties) {
    AwsBasicCredentials credentials = AwsBasicCredentials.create(
        r2Properties.getAccessKey(),
        r2Properties.getSecretKey()
    );
    
    S3Configuration s3Config = S3Configuration.builder()
        .pathStyleAccessEnabled(true)
        .build();
    
    return S3Client.builder()
        .endpointOverride(URI.create(r2Properties.getEndpoint()))
        .credentialsProvider(StaticCredentialsProvider.create(credentials))
        .region(Region.of(r2Properties.getRegion()))
        .serviceConfiguration(s3Config)
        .build();
}
```

### 2. 文件存储服务 (`FileStorageService.java`)

**核心方法**：

#### `uploadImage()`

- 验证文件（类型、大小、扩展名）
- 生成唯一文件名（UUID）
- 生成存储路径（按日期组织）
- 上传到 R2
- 保存记录到数据库
- 返回文件路径

#### `validateFile()`

- 检查文件是否为空
- 验证文件大小（≤ 5MB）
- 验证 MIME 类型
- 验证文件扩展名

#### `generateFilePath()`

- 按日期组织：`/uploads/YYYY/MM/DD/filename`
- 示例：`/uploads/2024/10/24/a1b2c3d4-e5f6-7890-abcd-ef1234567890.jpg`

### 3. 文件上传控制器 (`FileUploadController.java`)

**接口定义**：

```java
@Auth
@PostMapping("/image")
public ResponseEntity<Result> uploadImage(
    @RequestParam("file") MultipartFile file,
    @RequestParam(value = "fileType", required = false, defaultValue = "other") String fileType,
    HttpServletRequest request
)
```

**特点**：

- 使用 `@Auth` 注解进行 JWT 认证
- 支持 `fileType` 参数（avatar/course_image/other）
- 自动获取当前登录用户 ID
- 返回符合 API 文档的响应格式

### 4. 数据库设计 (`file_uploads` 表)

**字段说明**：

| 字段名               | 类型           | 说明          |
|-------------------|--------------|-------------|
| file_id           | BIGSERIAL    | 主键，自增       |
| original_filename | VARCHAR(255) | 原始文件名       |
| stored_filename   | VARCHAR(255) | 存储文件名（UUID） |
| file_path         | VARCHAR(500) | 文件相对路径      |
| file_size         | BIGINT       | 文件大小（字节）    |
| content_type      | VARCHAR(100) | MIME 类型     |
| upload_time       | TIMESTAMP    | 上传时间        |
| uploader_id       | BIGINT       | 上传者 ID      |
| file_type         | VARCHAR(50)  | 文件类型标识      |
| is_deleted        | SMALLINT     | 逻辑删除标记      |

**索引优化**：

- `idx_file_uploads_uploader_id`：按上传者查询
- `idx_file_uploads_file_type`：按文件类型查询
- `idx_file_uploads_upload_time`：按时间范围查询
- `idx_file_uploads_file_path`：唯一路径索引

## 🎯 API 接口规范

### 1. 上传图片

**请求**：

```http
POST /api/upload/image
Authorization: Bearer <jwt-token>
Content-Type: multipart/form-data

file: <binary-data>
fileType: avatar (可选)
```

**响应**：

```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "image_url": "/uploads/2024/10/24/a1b2c3d4-e5f6-7890-abcd-ef1234567890.jpg",
    "file_id": 1
  }
}
```

### 2. 删除文件

**请求**：

```http
DELETE /api/upload/{fileId}
Authorization: Bearer <jwt-token>
```

**响应**：

```json
{
  "code": 200,
  "message": "删除成功",
  "data": null
}
```

在 `pom.xml` 中添加：

```xml
<dependency>
    <groupId>software.amazon.awssdk</groupId>
    <artifactId>s3</artifactId>
    <version>2.20.26</version>
</dependency>
```

### 2. 配置 `application.yaml`（需要用户配置）

```yaml
# Cloudflare R2 存储配置
cloudflare:
  r2:
    access-key: "your-r2-access-key"
    secret-key: "your-r2-secret-key"
    bucket-name: "your-bucket-name"
    endpoint: "https://your-account-id.r2.cloudflarestorage.com"
    region: "auto"
    public-url: "https://your-custom-domain.com"

# Spring 文件上传配置
spring:
  servlet:
    multipart:
      max-file-size: 5MB
      max-request-size: 10MB
      enabled: true
```
