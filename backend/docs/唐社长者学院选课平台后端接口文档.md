# 产品文档 (PRD) 

一、产品概述

***\*产品名称：\**** 老年人选课平台

***\*产品类型：\**** 移动端优先的 Web 应用

***\*目标用户：\**** 50岁以上中老年群体

***\*产品目标：\****

帮助老年人方便地浏览课程、报名参加兴趣学习活动，提升生活幸福感和社交参与度。

------

## 二、设计原则与产品定位

### 1. 产品定位

一个“简单、清晰、友好”的线上课程报名系统，聚焦老年人群体的使用习惯。

### 2. 设计原则

| ***\*原则\****               | ***\*说明\****                                               |
| ---------------------------- | ------------------------------------------------------------ |
| ***\*移动端优先\****         | 页面默认设计为适配 375–480px 宽度的手机屏幕（如iPhone、国产安卓机） |
| ***\*大字体、大按钮\****     | 所有主要文字字号≥18px，按钮高度≥48px                         |
| ***\*高对比度与清晰配色\**** | 背景与文字对比明显，颜色柔和但醒目                           |
| ***\*简化操作流程\****       | 减少多层跳转，使用清晰的“下一步”指引                         |
| ***\*防误触设计\****         | 保留足够的点击间距，重要操作（如删除）需二次确认             |

------

## 三、系统角色与权限

| ***\*角色\****     | ***\*权限说明\****                             |
| ------------------ | ---------------------------------------------- |
| ***\*老人用户\**** | 注册、登录、浏览课程、选课、查看和修改个人信息 |
| ***\*管理员\****   | 管理课程（增删改查）、管理用户、查看报名情况   |

------

## 四、主要功能模块

### 1. 登录 / 注册模块

#### 功能说明

输入名字和密码进行注册

#### 功能点

- 输入名字密码登录

#### 交互设计

- 登录页按钮占屏宽 80%，字号 ≥ 18px
- 自动聚焦输入框并放大

------

### 2. 首页 / 课程浏览模块

#### 功能说明

展示所有课程，用户可点击进入课程详情进行选课。

#### 功能点

- 首页展示推荐课程（滚动卡片样式）
- 支持课程分类（如：手工、书法、太极、养生等）
- 课程卡片信息：封面图 + 名称 + 老师 + 报名人数
- 点击进入详情页，展示完整信息和“报名”按钮

#### 字段

| ***\*字段名\****        | ***\*类型\**** | ***\*是否必填\**** | ***\*说明\**** | ***\*备注\****               |
| ----------------------- | -------------- | ------------------ | -------------- | ---------------------------- |
| ***\*course_id\****     | INT            | ✅                  | 课程唯一ID     | 主键，自增                   |
| ***\*title\****         | VARCHAR(100)   | ✅                  | 课程名称       | 如“手工课”                   |
| ***\*category\****      | VARCHAR(50)    | ✅                  | 课程分类       | 手工 / 书法 / 太极 / 养生等  |
| ***\*description\****   | TEXT           | ✅                  | 课程简介       | 适合人群、内容介绍           |
| ***\*start_date\****    | DATE           | ✅                  | 开课日期       | 用于显示时间安排             |
| ***\*end_date\****      | DATE           | ❌                  | 结课日期       | 可选                         |
| ***\*class_time\****    | VARCHAR(100)   | ✅                  | 上课时间说明   | 周三上午9:00-10:30”          |
| ***\*location\****      | VARCHAR(100)   | ✅                  | 上课地点       | 如“社区活动中心201室”        |
| ***\*capacity\****      | INT            | ✅                  | 招生人数上限   | 用于报名限制                 |
| ***\*enrolled\****      | INT            | ✅                  | 已报名人数     | 默认0                        |
| ***\*status\****        | TINYINT        | ✅                  | 课程状态       | 0=未开始，1=进行中，2=已结课 |
| ***\*image_url\****     | VARCHAR(255)   | ❌                  | 课程封面图     | 图片存储路径或URL            |
| ***\*contact_phone\**** | VARCHAR(20)    | ❌                  | 联系电话       | 用于咨询课程                 |
| ***\*create_time\****   | DATETIME       | ✅                  | 创建时间       | 默认CURRENT_TIMESTAMP        |
| ***\*update_time\****   | DATETIME       | ✅                  | 最后更新时间   | 自动更新                     |
| ***\*is_deleted\****    | TINYINT        | ✅                  | 是否删除       | 0=正常，1=删除（逻辑删除）   |

#### UI 设计要点

- 单行展示 1 门课程卡片（图片居上）
- 按钮“报名课程”采用亮色、居中大按钮样式
- 课程详情页增加“返回上一页”显著入口

------

### 3. 选课 / 报名模块

#### 功能说明

老人可选择心仪课程报名，报名后课程进入“我的课程”页。

#### 功能点

- 报名时校验人数上限
- 若已满则显示“报名已满”并禁用按钮
- 报名后提示“报名成功”
- 支持取消报名（防误触二次确认）

------

### 4. 我的课程模块

#### 功能说明

展示用户已报名课程，方便查看时间和取消报名。

#### 功能点

- 查看课程列表（时间、老师、地点）
- 点击进入详情页查看信息
- 支持取消报名操作（防误触确认弹窗）

------

### 5. 个人中心模块

#### 功能说明

展示个人信息，支持修改。

#### 功能点

- 查看/修改姓名、性别、出生年月、联系方式
- 上传头像（移动端相册或拍照）
- 安全退出
- 可选：删除账户（逻辑删除）

#### 字段

| ***\*字段名\****           | ***\*类型\****  | ***\*是否必填\**** | ***\*说明\****       | ***\*备注\****                       |
| -------------------------- | --------------- | ------------------ | -------------------- | ------------------------------------ |
| ***\*user_id\****          | INT             | ✅                  | 用户唯一ID           | 主键，自增                           |
| ***\*name\****             | VARCHAR(50)     | ✅                  | 用户姓名             | 页面显示使用                         |
| ***\*gender\****           | ENUM('男','女') | ❌                  | 性别                 | 可选，默认空                         |
| ***\*age\****              | INT             | ❌                  | 年龄                 |                                      |
| ***\*phone\****            | VARCHAR(20)     | ❌                  | 手机号               |                                      |
| ***\*password\****         | VARCHAR(255)    | ✅                  | 登录密码（加密存储） | bcrypt加密                           |
| ***\*avatar_url\****       | VARCHAR(255)    | ❌                  | 用户头像             | 默认系统头像                         |
| ***\*hobbies\****          | VARCHAR(255)    | ❌                  | 兴趣爱好             | 可辅助推荐课程                       |
| ***\*health_condition\**** | VARCHAR(255)    | ❌                  | 健康情况             | 可用于筛选课程，如“适合膝关节不便者” |
| ***\*last_login_time\****  | DATETIME        | ❌                  | 上次登录时间         | 登录成功后更新                       |
| ***\*status\****           | TINYINT         | ✅                  | 账号状态             | 0=正常，1=禁用                       |

#### UI 设计要点

- 采用分块式卡片（信息项较少、层级扁平）
- 提供清晰“保存修改”按钮
- 顶部欢迎语，如“您好，张阿姨～”

------

### 6. 管理后台（Web端，非移动端）

管理员使用电脑端网页操作。

#### 功能点

- 用户管理
- 课程管理（增删改查）
- 报名信息查看（导出Excel）

------

## 六、移动端适配要求

| ***\*项目\****         | ***\*要求\****                                     |
| ---------------------- | -------------------------------------------------- |
| ***\*布局方式\****     | 响应式设计，采用 Flex 布局 + 媒体查询适配          |
| ***\*屏幕宽度适配\**** | 主流 360–480px（安卓）和 375px（iPhone）           |

# 🧓 唐社长者学院选课平台 -- 后端接口文档（API Specification）

## 一、接口总体说明

| 项目 | 内容 |
|------|------|
| **接口前缀** | `/api` |
| **认证方式** | JWT（登录成功后返回 `token`，后续接口通过 `Authorization` 头携带） |
| **返回格式** | `{ code: 0, message: 'success', data: {...} }` |
| **分页参数** | `page`（页码），`pageSize`（每页数量） |
------------------------------------------------------------------------

## 二、登录注册模块

### 1. 注册用户

**POST** `/api/register`

**请求参数**

``` json
{
  "name": "张阿姨",
  "password": "123456"
}
```

**返回参数**

``` json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "user_id": 1,
    "token": "xxxxx.yyyyy.zzzzz"
  }
}
```

------------------------------------------------------------------------

### 2. 用户登录

**请求参数**

{
