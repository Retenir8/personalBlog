# 文件上传功能配置说明

## 一、功能概述

本系统实现了基于 Cloudflare R2 的文件上传功能，支持图片上传、存储和管理。

### 主要特性

- ✅ **云存储集成**：使用 Cloudflare R2（兼容 S3 API）
- ✅ **文件验证**：支持 JPG、PNG、GIF、WEBP 格式
- ✅ **大小限制**：单文件最大 5MB
- ✅ **安全命名**：UUID + 原始扩展名，避免文件名冲突
- ✅ **目录组织**：按日期分层存储（/uploads/YYYY/MM/DD/）
- ✅ **数据库记录**：完整的文件上传记录追踪
- ✅ **权限控制**：需要登录认证（JWT）
- ✅ **错误处理**：完善的异常处理机制

## 二、配置步骤

### 1. 添加 R2 配置到 `application.yaml`

在 `src/main/resources/application.yaml` 中添加以下配置：

```yaml
# Cloudflare R2 存储配置
cloudflare:
  r2:
    # R2 Access Key（从 Cloudflare 控制台获取）
    access-key: "your-r2-access-key"

    # R2 Secret Key（从 Cloudflare 控制台获取）
    secret-key: "your-r2-secret-key"

    # 存储桶名称
    bucket-name: "your-bucket-name"

    # R2 端点 URL（格式：https://<账户ID>.r2.cloudflarestorage.com）
    endpoint: "https://your-account-id.r2.cloudflarestorage.com"

    # 区域（R2 使用 "auto"）
    region: "auto"

    # 公开访问 URL（可选，用于生成文件访问链接）
    # 如果配置了自定义域名，填写自定义域名
    # 如果使用 R2 公开 URL，填写 R2 提供的公开 URL
    public-url: "https://your-custom-domain.com"

# Spring 文件上传配置
spring:
  servlet:
    multipart:
      # 单个文件最大大小
      max-file-size: 5MB
      # 单次请求最大大小
      max-request-size: 10MB
      # 是否启用文件上传
      enabled: true
```

### 2. 获取 Cloudflare R2 凭证

#### 步骤 1：登录 Cloudflare 控制台

访问：https://dash.cloudflare.com/

#### 步骤 2：创建 R2 存储桶

1. 进入 **R2** 页面
2. 点击 **创建存储桶**
3. 输入存储桶名称（例如：`course-uploads`）
4. 选择区域（建议选择离用户最近的区域）
5. 点击 **创建**

#### 步骤 3：生成 API 令牌

1. 在 R2 页面，点击 **管理 R2 API 令牌**
2. 点击 **创建 API 令牌**
3. 设置权限：
    - **对象读取和写入**（Object Read & Write）
    - 选择刚创建的存储桶
4. 点击 **创建 API 令牌**
5. 复制 **Access Key ID** 和 **Secret Access Key**

#### 步骤 4：获取端点 URL

在 R2 存储桶详情页面，找到 **S3 API** 部分，复制端点 URL。

格式通常为：`https://<账户ID>.r2.cloudflarestorage.com`

#### 步骤 5：配置公开访问（可选）

如果需要通过 URL 直接访问文件：

1. 在存储桶设置中，启用 **公开访问**
2. 或者配置 **自定义域名**
3. 将公开 URL 填入 `public-url` 配置项

### 3. 执行数据库迁移

运行 SQL 脚本创建文件上传记录表：

```bash
# 使用 psql 命令行工具
psql -h 178.128.209.33 -p 5432 -U lzyyy -d course -f docs/file_uploads_table.sql

# 或者在数据库管理工具中执行 docs/file_uploads_table.sql 文件
```

## 三、API 接口说明

### 1. 上传图片

**接口地址**：`POST /api/upload/image`

**请求方式**：`multipart/form-data`

**请求头**：

```
Authorization: Bearer <your-jwt-token>
Content-Type: multipart/form-data
```

**请求参数**：

| 参数名      | 类型     | 必填 | 说明                                         |
|----------|--------|----|--------------------------------------------|
| file     | File   | ✅  | 上传的图片文件                                    |
| fileType | String | ❌  | 文件类型标识（avatar/course_image/other），默认 other |

**响应示例**：

```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "image_url": "/uploads/2024/10/24/a1b2c3d4-e5f6-7890-abcd-ef1234567890.jpg",
    "file_id": 1
  }
}
```

**错误响应**：

```json
{
  "code": 400,
  "message": "文件大小不能超过 5MB",
  "data": null
}
```

### 2. 删除文件（逻辑删除）

**接口地址**：`DELETE /api/upload/{fileId}`

**请求头**：

```
Authorization: Bearer <your-jwt-token>
```

**响应示例**：

```json
{
  "code": 200,
  "message": "删除成功",
  "data": null
}
```

## 四、前端调用示例

### JavaScript / Fetch API

```javascript
// 上传图片
async function uploadImage(file) {
    const formData = new FormData();
    formData.append('file', file);
    formData.append('fileType', 'avatar'); // 可选

    const response = await fetch('/api/upload/image', {
        method: 'POST',
        headers: {
            'Authorization': `Bearer ${localStorage.getItem('token')}`
        },
        body: formData
    });

    const result = await response.json();

    if (result.code === 200) {
        console.log('上传成功:', result.data.image_url);
        return result.data.image_url;
    } else {
        console.error('上传失败:', result.message);
        throw new Error(result.message);
    }
}

// 使用示例
const fileInput = document.getElementById('fileInput');
fileInput.addEventListener('change', async (e) => {
    const file = e.target.files[0];
    if (file) {
        try {
            const imageUrl = await uploadImage(file);
            console.log('文件路径:', imageUrl);
            // 更新用户头像或课程封面
        } catch (error) {
            alert('上传失败: ' + error.message);
        }
    }
});
```

### Axios

```javascript
import axios from 'axios';

async function uploadImage(file, fileType = 'other') {
    const formData = new FormData();
    formData.append('file', file);
    formData.append('fileType', fileType);

    try {
        const response = await axios.post('/api/upload/image', formData, {
            headers: {
                'Authorization': `Bearer ${localStorage.getItem('token')}`,
                'Content-Type': 'multipart/form-data'
            }
        });

        return response.data.data.image_url;
    } catch (error) {
        console.error('上传失败:', error.response?.data?.message);
        throw error;
    }
}
```

## 五、文件存储结构

### 目录组织

```
R2 存储桶根目录/
└── uploads/
    └── 2024/
        └── 10/
            └── 24/
                ├── a1b2c3d4-e5f6-7890-abcd-ef1234567890.jpg
                ├── b2c3d4e5-f6a7-8901-bcde-f12345678901.png
                └── ...
```

### 文件命名规则

- **格式**：`UUID.扩展名`
- **示例**：`a1b2c3d4-e5f6-7890-abcd-ef1234567890.jpg`
- **优点**：
    - 避免文件名冲突
    - 防止路径遍历攻击
    - 隐藏原始文件名，提高安全性

## 六、安全性说明

### 1. 文件类型验证

- **MIME 类型检查**：验证 `Content-Type`
- **扩展名检查**：验证文件扩展名
- **双重验证**：同时检查 MIME 类型和扩展名

### 2. 文件大小限制

- **单文件限制**：5MB
- **请求总大小限制**：10MB

### 3. 权限控制

- **登录认证**：所有上传接口需要 JWT 认证
- **用户追踪**：记录上传者 ID

### 4. 文件名安全

- **UUID 命名**：避免文件名冲突和路径遍历
- **扩展名白名单**：仅允许特定扩展名

## 七、故障排查

### 问题 1：上传失败，提示 "文件上传到云存储失败"

**可能原因**：

- R2 凭证配置错误
- 存储桶名称错误
- 端点 URL 错误
- 网络连接问题

**解决方法**：

1. 检查 `application.yaml` 中的 R2 配置
2. 验证 Access Key 和 Secret Key 是否正确
3. 确认存储桶名称和端点 URL
4. 检查服务器网络连接

### 问题 2：上传成功但无法访问文件

**可能原因**：

- 存储桶未配置公开访问
- 自定义域名未配置

**解决方法**：

1. 在 Cloudflare 控制台启用存储桶公开访问
2. 或配置自定义域名
3. 更新 `public-url` 配置

### 问题 3：文件大小超限

**错误信息**：`文件大小不能超过 5MB`

**解决方法**：

- 压缩图片后再上传
- 或调整 `application.yaml` 中的 `max-file-size` 配置

## 八、性能优化建议

### 1. CDN 加速

配置 Cloudflare CDN 加速文件访问：

- 在 R2 存储桶设置中启用 CDN
- 配置自定义域名并启用 Cloudflare 代理

### 2. 图片压缩

前端上传前进行图片压缩：

```javascript
// 使用 browser-image-compression 库
import imageCompression from 'browser-image-compression';

async function compressAndUpload(file) {
    const options = {
        maxSizeMB: 1,
        maxWidthOrHeight: 1920,
        useWebWorker: true
    };

    const compressedFile = await imageCompression(file, options);
    return uploadImage(compressedFile);
}
```

### 3. 缓存策略

设置合理的缓存头：

- 在 R2 上传时设置 `Cache-Control` 头
- 建议：`Cache-Control: public, max-age=31536000`

## 九、维护和监控

### 1. 清理无用文件

定期清理标记为删除的文件：

```sql
-- 查询已删除的文件
SELECT *
FROM file_uploads
WHERE is_deleted = 1;

-- 物理删除（需要同时删除 R2 中的文件）
DELETE
FROM file_uploads
WHERE is_deleted = 1
  AND update_time < NOW() - INTERVAL '30 days';
```

### 2. 监控存储使用

在 Cloudflare 控制台查看：

- 存储空间使用量
